# FeeSweep

The creator fee command center for Solana launchpads.

Creators earn perpetual fees across a fragmented launchpad landscape (Bags, Pump.fun, LetsBonk, Jupiter Studio) with no unified view of what they've earned, what's sitting unclaimed, or any automation for what happens after the claim.

**FeeSweep:** paste a wallet → see everything earned and claimable across platforms, free. Set a policy once — "when claimable fees pass 0.5 SOL: claim, swap 60% to USDC to treasury, 25% SOL to marketing, 15% to the holder-dividend pool" — and sign each sweep in one click. Non-custodial, propose-then-sign; we never touch keys or funds.

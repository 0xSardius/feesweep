# FeeSweep — Lessons Learned

Running log of what we learn building FeeSweep — market truths, technical gotchas, user feedback, and decisions that turned out right or wrong. One file per dated entry: `YYYY-MM-DD-<topic>.md`.

Convention per entry:
- **Lesson:** the thing we now know
- **Evidence:** how we know it (link, data, user quote, incident)
- **Decision changed:** what we're doing differently because of it

Read this folder at the start of every FeeSweep session (it's referenced from the root CLAUDE.md workflow).
